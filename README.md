# qPCR 数据整理台

适用于 **96 孔和 384 孔板**。导入仪器导出的 TXT／TSV，在孔板图上分配样本、基因和技术副孔，再检查数据、编辑版式并导出 Excel。两种板型共用同一套选孔和报表编辑操作。

**当前版本 v1.9.4 · 仅供测试与学习使用**

| 使用入口 | 怎么打开 |
| --- | --- |
| [直接打开网页版](https://mobiusj.github.io/qpcr-workbench/qPCR-384.html) | 手机、平板和电脑都可直接使用。 |
| [下载 macOS 版](https://mobiusj.github.io/qpcr-workbench/qPCR-384-macOS.zip) | 解压后打开 `qPCR 384.app`。当前安装包使用本地签名，遇到系统验证提示时可使用网页版。 |
| [下载 Windows 版](https://mobiusj.github.io/qpcr-workbench/qPCR-384-Windows.zip) | 完整解压到文件夹，再双击 `Start qPCR 384.cmd`。 |

想添加到手机主屏幕或缓存后离线使用，可从[下载与使用页面](https://mobiusj.github.io/qpcr-workbench/)进入。iPhone 和 iPad 用 Safari 的「分享 → 添加到主屏幕」，Android 用 Chrome 菜单里的「安装应用」或「添加到主屏幕」。页面显示「网页已缓存，可离线使用」后，即可用同一浏览器离线打开。

## v1.9.4 更新内容

- 「导出前检查」新增参考 Cp 表对账。可读取同批手算表或兼容的定量分析表，逐格比较分组、样本、基因和副孔的原始 Cp，并定位当前孔位。
- 定量检查及导出的「孔位与计算说明」新增配对与校准明细，列出每个靶标和分组的有效副孔数、样本数、校准基准，以及存在缺失配对的样本。

## v1.9.3 更新内容

- 96 孔和 384 孔的主板图、区域编辑器均支持「按孔设置基因」。同一行或列可放不同样本和基因，每个基因可以使用不同数量或不连续的副孔。
- 指定孔位的基因优先使用按孔设定，其余样本孔仍沿用行列基因。「自动识别」可核对每孔的基因和副孔编号，布局 JSON 支持保存和共享按孔设定。

## v1.9.2 更新内容

- 96 孔和 384 孔主板图中的样本区域使用不同颜色的半透明边框和底色。样本名显示在框内顶部，孔内的 Cp 数值仍可直接读取。
- 单击样本框内任一孔位选中整个区域。板图上方可查看样本名、分组、孔位和孔数，也可打开样本编辑。双击框内孔位可只选这一孔。

## v1.9.1 更新内容

- 96 孔和 384 孔主板图都可在拖选后直接编辑样本。设置基因或切换孔板时，正在填写的样本信息和选区会保留。
- 主板图可直接点行号或列号设置基因，并从常用内参中选择。主板图和区域编辑器均可按行或按列重复填充基因，保留基因顺序和角色。
- 主板图提供自动识别副孔与共享布局。页眉显示当前版本，板图工具栏、选孔高亮和窄屏排版也已优化。

## 第一次使用

### 1. 选择板型并导入文件

1. 在页面上方选择「96 孔」或「384 孔」。96 孔板是 A1–H12，384 孔板是 A1–P24。
2. 点「添加孔板文件」。每块板对应一份以制表符分隔的 TXT 或 TSV，可一次选择多份文件。孔位列可用 `Pos`、`Well` 或 `Position`，读数列可用 `Cp`、`Ct` 或 `Cq`。
3. 如果弹出「Late Cp 标记设置」，可以留空阈值并点「确认并导入」。设置阈值只会增加高亮提示，原始读数照常保留，未检出值继续留空。
4. 导入多块板后，板图上方会显示 `P1`、`P2` 等标签。先核对板号旁的文件名，再开始分配。

### 2. 像在 Excel 里一样框选样本区域

点「打开区域编辑器 → 试用五基因示例」，可以先用内置示例查看区域编辑和副孔识别。开始处理自己的数据时，点「返回实际孔板」。

假设样本一和样本二各有 5 个基因，每个基因有 3 个技术副孔。同一行放同一个基因，可按下图理解孔位。

| 行 | 第 1–3 列 · 样本一 | 第 4–6 列 · 样本二 | 基因角色 |
| --- | --- | --- | --- |
| A | A1–A3 | A4–A6 | 内参基因 |
| B | B1–B3 | B4–B6 | 目的基因 1 |
| C | C1–C3 | C4–C6 | 目的基因 2 |
| D | D1–D3 | D4–D6 | 目的基因 3 |
| E | E1–E3 | E4–E6 | 目的基因 4 |

1. 在主板图从 A1 拖到 E3。松手后填写样本名和分组，再点「保存样本」。以同样方式从 A4 拖到 E6 保存样本二。手机上可勾选「两点选区」，分别轻点起点和终点。
2. 点 A 行的行号，填写基因名称并选择「内参基因」，也可直接从「常用内参」选择。继续为 B–E 行填写目的基因。主板图点列号也能设置基因，保存后按列识别。可随时从「基因位置」选择识别方向。
3. 同一组基因需要连续重复时，点「重复填充基因」，选来源起点、来源终点和填充终点。例如选 A–E 为来源、填充到 J，就会在 F–J 按同样顺序填入基因和角色。先核对预览，再点「应用填充」。
4. 点「自动识别」预览副孔组。核对孔位、样本、基因和副孔号后，点「保存映射」。

矩形范围使用「矩形框选」，例如 `A1:E3`。如果孔位沿行排布并从上一行末尾接到下一行开头，选择「跨行连续」。例如 96 孔板的 `A11-B2` 包含 A11、A12、B1、B2。先点起点再按住 Shift 点终点也能选取范围。

同一个样本占用几个不相邻的矩形时，先框选一块，再按住 Ctrl（Mac 用 ⌘）拖选另一块，最后保存为同一个样本。使用触屏时，可同时勾选「追加选区」和「两点选区」，每块分别轻点两个对角，全部选好后从「选孔操作」打开「编辑样本区域」。

### 同一行或列混排不同基因

1. 先按实际孔位保存各样本的区域。在一个样本分布于多处时，可用逗号把多个范围填入同一个样本的「孔位」栏。两个样本不能占用同一个孔。
2. 从主板图或区域编辑器点「按孔设置基因」。选中样本区域后，输入这一组基因占用的孔，例如 384 孔板的样本 87 在 `O1:O3` 设置 ACTB（内参）、在 `P1:P3` 设置 ACSL6（目的）。另一个样本可以反过来排布，也可以用不同数量的副孔。同一孔不能重复分配，若下一个样本紧接 O3 开始，核对后填写例如 `O4:O6`。
3. 起始副孔编号留空时，按当前行列方向为同一样本区域内的同一基因编号。需要保留编号空档时，可分段指定起始编号。自动识别后点击孔位核对，保存映射前确认每个样本、基因和副孔号。定量仍按相同副孔编号配对，缺少有效 Cp 的一侧留空。

### 3. 按需要调整孔位或处理多块板

- **改错后重新导出。** 在主板图单击样本框，用板图上方的「编辑样本」修改范围、样本名或分组。也可右键使用「编辑样本区域」。也可以从「打开区域编辑器」选择孔板和样本。基因名称和角色从对应的行号或列号修改。点「自动识别」核对，再点「保存映射」并重新生成 Excel。
- **只改几个孔。** 在主板图选好孔，点「手动分配」。双击样本框内的孔可单独选中该孔，如需调整同基因的整组副孔，可从右键菜单打开「编辑整组副孔」。NTC 或排除孔也可通过「手动分配」设置。
- **一次处理多块板。** 在主板图中分别选出各板的孔位，切换板号时选区会保留。点「批量分配各板选区」可一次送入批量预览。384 孔顺序分配时，勾选「允许同组副孔跨板」可让同一组副孔换板后接着编号。也可在区域编辑器内通过「查看板」逐块设置样本和行列基因，全部设置完成后点一次「自动识别」。保存前按板号核对首尾孔和换板位置。
- **保存和共享。** 已生效的孔位映射可通过「导入或编辑孔位映射表 → 保存映射 TSV」带到下次会话。要共享可继续编辑的区域布局，在主板图或区域编辑器内打开「共享布局」，点「复制布局」或「导出 JSON」。接收方选相同板型并导入对应孔板，在同一窗口展开「导入布局」，粘贴文本或选择 JSON，核对目标板后载入，再自动识别并保存映射。

### 4. 检查并导出 Excel

1. 在「检查数据并导出 Excel」勾选所需报表。「Cp 数据整理表」按分组、样本、基因和副孔整理原始读数。「定量分析结果表」根据内参和所选方法计算结果。96 孔模式可在「当前报表孔板」里选板，逐板预览和导出。
2. 需要定量结果时，核对内参和计算方法。选择比较 Ct 法时，再确认「校准样本组」。96 孔模式使用当前板的内参与校准数据。
3. 点「检查数据」，先处理未分配的有效 Cp 孔、缺失的内参和其他提示。确实要跳过某些未分配孔时，可勾选「允许跳过未分配的有效 Cp 孔」，这些孔仍会记录在 Excel 说明页。
4. 点报表卡片上的「预览表格」，确认样本、基因和副孔顺序。需要时修改文件名，再点「生成所选 Excel」。如果预览标为「示例数据」，先按提示补齐当前数据所需的设置。

### 核对手算表与孔位

在「导出前检查」展开「核对参考 Cp 表」，选择同一批实验的 .xlsx。参考表使用原始 Cp，A–C 列依次是基因、分组和样本，D 列起为副孔 Cp，最后接一列 mean。支持工作台内置定量表的排列。也可保留原表中的 ΔCt 与后续公式。对账仅使用原始 Cp，未检出的 Cp 可留空。检查发现差异时，点孔位可返回板图，核对上板记录后再修改映射。

在「配对与校准明细」可查看有效副孔和样本数。比较 Ct 模式按每个内参与靶标各自计算校准基准。未检出或缺失的一侧保持空白，后续编号维持原位。

## 像 Excel 一样自定义报表

1. 在已有报表卡片上点「自定义版式」，或点「＋ 添加自定义表」创建一张表。新表可选择空白表格、Cp 数据或定量结果作为数据来源。可以继续添加多张，每张都能独立命名、预览和勾选导出。
2. 在网格中选中单元格直接输入，或双击编辑。也可以从 Excel 或 WPS 复制一个区域，再选中起始格粘贴。工具栏提供填充、对齐和合并，「行列操作」里可插入、删除和移动列。
3. 希望导出时自动填充的内容，用「插入字段」绑定。比如在第一行写「样本」「基因」，在第二行对应位置分别插入样本和基因字段。需要一起逐行填充的字段应放在同一数据行。
4. 点「应用版式」，回到报表卡片预览，核对表头、字段和样式后再导出。

已有 Excel／WPS 模板时，展开页面底部的「高级版式设置」。在「字段表单与 Excel 模板」中可下载样板、用表单编辑或导回样板。编辑样板时，把 `[[样本]]`、`[[基因]]` 等字段标记放在同一行，导回后先核对字段和列。也可使用「提取 Excel / 图片样式」沿用外部配色。

## 常见问题

| 遇到的问题 | 怎么处理 |
| --- | --- |
| 文件导入失败 | 确认是制表符分隔的 TXT／TSV，检查孔位和 Cp 表头。孔位超出当前板型时，保存已有映射后切换到对应板型，再导入文件。 |
| 孔位从上一行末尾接到下一行 | 选择「跨行连续」。需要跨几行框出一整块时，选择「矩形框选」。 |
| 定量结果表无法生成 | 先看「检查数据」的提示，核对当前板、内参、技术副孔和适用的校准组。只需整理原始读数时，可单独勾选 Cp 数据整理表。 |
| 下次还想用同一套孔位 | 区域布局用「共享布局」导出 JSON。希望恢复已生效的逐孔分配时，用「保存映射 TSV」。建议在刷新、关闭页面或切换板型前保存。 |

## 隐私政策

- **本机处理。** 导入的仪器 TXT／TSV、孔位映射、用于取样式的 Excel 或图片，以及生成的 Excel，均由应用在设备本机处理，应用不会将这些文件上传至项目服务器。工具无需账号。
- **网页访问。** 通过 GitHub Pages 打开页面或下载软件时，浏览器会向 GitHub 请求页面和文件，浏览器也可能缓存离线资源。GitHub 对访问数据的处理见 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
- **主动共享。** 布局 JSON 不含实验 Cp 读数，但可能带有板的标识、样本名、分组、基因名和孔位。分享前请检查这些名称是否需要脱敏。提交公开反馈时，请用虚构数据或脱敏后的截图。
