# qPCR 数据整理台

**本项目仅供测试与学习使用，禁止商用。**

qPCR 数据整理台用于整理 384 孔和 96 孔板的仪器导出数据。它可以按分组、样本、基因和技术副孔整理 Cp，支持孔位映射、内参归一化、报表预览和 Excel 导出。

## 打开方式

| 设备 | 使用方式 |
| --- | --- |
| Android、iPhone、iPad | 打开本项目的 GitHub Pages 链接，点「直接打开网页版」。Android 可用 Chrome 菜单安装网页应用，iPhone 和 iPad 可在 Safari 中通过「分享 → 添加到主屏幕」使用。 |
| Windows | 可直接使用网页版，也可下载 [Windows 便携版](./qPCR-384-Windows.zip)。完整解压后，双击 `Start qPCR 384.cmd`。 |
| macOS | 可直接使用网页版，也可下载 [Mac 版](./qPCR-384-macOS.zip)。解压后打开 `qPCR 384.app`。当前安装包使用本地签名，系统若提示无法验证，可使用网页版。 |

网页版入口可在 GitHub 仓库右侧 **About** 的网站链接中找到，也可使用维护者分享的 GitHub Pages 地址。首次联网打开下载页，等页面显示「网页已缓存，可离线使用」，即可在该浏览器中断网使用。

## 快速上手

1. **选择孔板。** 默认是 384 孔。处理 96 孔数据时，在页头切换到「96 孔」。切换前可先保存已有的孔位映射 TSV。
2. **导入仪器文件。** 每块孔板对应一份制表符分隔的 TXT 或 TSV。384 孔模式读取 `Pos` 和 `Cp`。96 孔模式也接受 `Well` 或 `Position` 作为孔位列，以及 `Ct` 或 `Cq` 作为读数列。
3. **分配孔位。** 按实际排板填写分组、样本、基因和副孔编号，标记内参、目的基因和 NTC。可手动分配，也可按区域或批量分配。未使用的孔可以留空。
4. **检查并导出。** 预览「Cp 数据整理表」或「定量分析结果表」，核对后生成 `.xlsx`。96 孔模式按当前选中的孔板预览和导出，定量使用同一块板的内参和校准数据。缺失读数留空。

若需要自定义 Excel／WPS 版式，可从对应报表的「自定义版式」下载样板，保留同一行的 `[[字段名]]` 标记。导回后先核对字段和列，再应用版式。

## 文件与隐私

实验文件、孔位映射和生成的 Excel 在设备本机处理，应用不会将其上传。通过 GitHub Pages 访问时，浏览器会联网加载网页和下载资源。请保留原始仪器文件及核对过的孔位映射，便于复查。
